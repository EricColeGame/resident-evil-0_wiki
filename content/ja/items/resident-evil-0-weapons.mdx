バイオハザード0の武器は、クラシックシリーズの中で最も扱いにくい武器一式だ。それにはちゃんとした理由がある。このゲームにはアイテムボックスが存在しないのだ。セーブルームごとに魔法のような収納チェストが待っている代わりに、与えられるのは床と、2人のキャラクターと、それぞれ6つのアイテムスロットだけ。拾った武器はすべて、ハーブや鍵アイテム、弾薬に使えないスロットを1つ占有する。そして3部屋も離れた場所に置き去りにしたショットガンは、プロトタイラントがドアをくぐってきたときに手元にないショットガンなのだ。

このたった一つの設計判断が、ゲーム全体を一変させる。どの銃器がスロットに見合う価値があるのか、どの弾薬タイプを溜め込むべきか、そしてパートナーザッピングシステムが武器の扱い方をどう変えるのかを理解しているかどうかが、スムーズな攻略と資源破綻の分かれ目になる。本ガイドではすべての銃器を分解して解説し、ランク付けし、2周目をずっと楽にしてくれるアンロック要素も網羅する。

## バイオハザード0の武器庫が一味違う理由

ほとんどのクラシック『バイオハザード』では、あなたは溜め込む。アイテムボックスを埋め、後で戻ってきて、状況に必要なものを取り出す。バイオハザード0はその安全網を削除した。

アイテムは落とした場所に、キャンペーン全体を通して永久に留まる。黄道特急の食堂車に置き忘れたグリーンハーブは、黄道特急の食堂車に残り続ける。ゲームは部屋ごとにドロップアイテムを管理しているので、「駐車」はギャンブルではなく正当な戦略だ。

さらにその上にパートナーザッピングシステムが重なる。レベッカ・チェンバースとビリー・コーエンを同時に操作し、瞬時に切り替えてアイテムをやり取りできる。武器はキャラクターに属するものではない。次のドアが開いたときにそれを持っている者のものなのだ。

### レベッカ vs. ビリー：誰が何を持つべきか

| 特性 | レベッカ・チェンバース | ビリー・コーエン |
|---|---|---|
| 役割 | 回復とサポート | 前線の戦闘要員 |
| ハーブ調合 | 可 — 自由にハーブを調合できる | 不可 |
| 重い物体 | 押せない | 木箱や棚を押せる |
| 耐久力 | 体力が低い | 体力が高い |
| 銃器の使用 | すべての武器 | すべての武器 |
| 最適な武器構成 | 精密射撃とサポート用の銃 | 近距離・高火力の武器 |

**実践的なルール：** ショットガンとマグナムはビリーに持たせよう。その場に踏みとどまって一撃を受け止められるのは彼だからだ。レベッカにはハンティングガン、グレネードランチャー、そしてハーブ類を担当させる。コミュニティの報告も一貫してこの分担を支持している。ビリーの高い耐久力のおかげで、近距離の撃ち合いがはるかに痛手にならないからだ。

## 弾薬タイプ、レア度、温存すべきもの

弾薬こそが、バイオハザード0の武器で本当に胃が痛くなる部分だ。ゲーム内の各銃器はそれぞれ別の供給ラインで動いており、レアな弾は新規プレイヤーが想像するよりずっとレアである。

| 弾薬 | 使用武器 | レア度 | 備考 |
|---|---|---|---|
| ハンドガンの弾 | ハンドガン、サブマシンガン | 一般的 | 基本の弾薬。常に補充を |
| ショットガンの弾 | ショットガン | やや希少 | 狭い拡散、近距離で壊滅的 |
| グレネード弾 | グレネードランチャー | 希少 | 爆発による範囲ダメージ |
| アシッド弾 | グレネードランチャー | 希少 | 硬い装甲の敵に有効 |
| フレイム弾 | グレネードランチャー | 希少 | 広範囲に安定したダメージ |
| ライフルの弾 | ハンティングガン | 非常に希少 | 単発、高ダメージ、遅い |
| マグナムの弾 | マグナム | 非常に希少 | ボス専用。ゾンビには絶対に使わない |

経験豊富なプレイヤーが守る経験則はこうだ。「非常に希少」な弾はボス用に取っておく。黄道特急のジャイアントバット、プロトタイラントとの遭遇戦、そしてクイーンリーチの最終戦こそ、マグナムを撃ち尽くす価値のある戦いだ。それ以外の場面はハンドガンの弾とナイフ、そして環境が与えてくれるもので対処すべきである。

火炎瓶のような投擲アイテムは有用な中間手段だ。弾薬を消費せずに大きなダメージを与えられるが、スロットを取り、数も限られる。敵の群れや撤退の援護のために取っておき、ゾンビ1体に使うのは避けよう。

## バイオハザード0の最強武器ランキング

このランキングは純粋なダメージ、弾薬経済、そして各武器がどれだけインベントリを圧迫するかを考慮している。プレイヤーの体験はさまざまだが、以下のティアはコミュニティの総意を反映している。

| ティア | 武器 | この位置の理由 |
|---|---|---|
| S | マグナム | ゲーム内最高の単発ダメージ。ボスを無力化 |
| S | グレネードランチャー | 範囲ダメージ＋3種類の属性弾 |
| A | ショットガン | 中盤のキャンペーンを通して最高の群れ制圧力 |
| A | ハンティングガン | 圧倒的な射程とダメージ。ただしボルトアクションは遅い |
| B | ハンドガン | 働き者。弾は安く、無駄にならない |
| B | サブマシンガン | アンロック後はバースト射撃で群れを粉砕 |
| C | コンバットナイフ | タダのダメージだが、立っている敵には危険 |
| C | 火炎瓶 | 状況依存、数限定、スロットを食う |

マグナムの価値はダメージだけではない。悪い状況を20発ではなく2発で終わらせる能力だ。グレネードランチャーの価値は柔軟性にあり、グレネード弾、アシッド弾、フレイム弾を切り替えることで、武器を持ち替えずにゲームが投げかけるあらゆる状況に適応できる。

ショットガンはゲーム内で最も*快適な*武器であり続ける。寛容で、弾も定期的に手に入り、アンブレラ幹部養成所を象徴する狭い廊下の戦いを解決してくれる。

## アンロック武器とボーナスコンテンツ

バイオハザード0を一度クリアするとリーチハンターがアンロックされる。これは時間制限付きの収集モードで、養成所を巡回してリーチチャームを集めながら、復活する敵と戦う。これがゲームのボーナス火力への主なルートだ。

| アンロック要素 | 条件 | 獲得内容 |
|---|---|---|
| リーチハンターモード | メインキャンペーンをクリア | 独自の報酬を持つ単体ミニゲーム |
| サブマシンガン | リーチハンターでリーチを100体すべて集める | メインゲームで使用可能なバースト射撃武器 |
| リーチハンター部分報酬 | より少ないリーチ数の達成 | 小規模な消費アイテム報酬 |
| ウェスカーモード | キャンペーンをクリア（HDリマスター） | 強化能力を持つアルバート・ウェスカーを操作 |
| 追加コスチューム | キャンペーンとボーナスモードをプレイ | 見た目の衣装チェンジ |

コミュニティの報告によれば、サブマシンガンは最も影響力のあるアンロック要素だ。普通の廊下の戦闘を素早く低リスクな処理に変えてくれるからである。それを狙うなら、両キャラクターでリーチハンターをクリアし、タイムを気にする前にチャームの位置を覚えることを優先しよう。

2016年のHDリマスター — [Steamのバイオハザード0 HDリマスター](https://store.steampowered.com/app/339340/Resident_Evil_0_HD_Remaster/)で入手可能 — は、現在多くのプレイヤーが触れるバージョンであり、リーチハンターとウェスカーモードの両方が最初から収録されている。

## バイオハザード0の武器管理の実践的なコツ

- **1キャラクターにつき銃は2丁まで。** 3丁目を持つということは、ハーブや鍵アイテムを置き去りにしているということだ。
- **予備の武器はハブとなる部屋に置く。** 養成所のメインホールや列車の中央車両は、何度も通る部屋だ。
- **弾薬はそれが使われる武器の隣に落とす。** ショットガンとその弾をマップ上で引き離すのは、このゲームで最も多い自滅ミスだ。
- **ハーブはレベッカに、調合結果はビリーに。** ビリーは調合できないが、レベッカが用意したものを持ち運び、使うことはできる。
- **倒れた敵にはナイフを使う。** コストはゼロで、まだ立っている脅威のためにハンドガンの弾を節約できる。
- **マグナムとライフルの弾はボス部屋まで貯める。** 通常の敵に使ったレア弾は、プロトタイラント戦で持っていない弾だ。
- **ドアを開ける前に武器を交換する。** ザッピングシステムは瞬時だが、ゾンビの掴みはメニュー操作より速い。
- **火炎瓶は緊急ボタンとして扱う。** 包囲からの脱出には最適だが、通常の敵処理には向かない。

もう一つ身につけたい習慣がある。大きなセクションを終えるたびに、次へ進む前に簡単なインベントリの見直しをしよう。バイオハザード0の武器は、それをもう一度見つけられるかどうかでしか価値を持たない。そしてゲームは、何を置き去りにしたかを教えてはくれない。

## FAQ

**バイオハザード0の武器で最強なのは？**

1発あたりの威力ではマグナムが最強で、グレネードランチャーが最も汎用性が高い。ただし一般的なプレイでは、キャンペーン全体を通して最も活躍するのはショットガンだ。弾が比較的よく手に入り、ゲームの大半を占める狭い戦いを解決してくれるからである。

**バイオハザード0ではレベッカとビリーの両方がすべての武器を使える？**

はい。両キャラクターはマグナム、グレネードランチャー、ハンティングガンを含むすべての銃器を撃てる。違いは武器へのアクセスではなく、耐久力とユーティリティにある。ビリーは重い物体を押せて多くの攻撃に耐え、レベッカはハーブを調合できる。

**バイオハザード0でサブマシンガンをアンロックするには？**

メインキャンペーンをクリアしてリーチハンターをアンロックし、そのモードでリーチを100体すべて集める。コミュニティの報告によれば、その後サブマシンガンがメインゲームで使用可能になり、ハンドガンの弾で動くため維持が非常に簡単だ。

**バイオハザード0をクリアするのにハンティングガンは必要？**

いいえ。ただし長い廊下のセクションをいくつかずっと安全にしてくれる。ライフルの弾は極めて希少なので、ハンティングガンは主力武器ではなく、危険な単体ターゲット用の精密ツールとして扱おう。インベントリの空きが厳しいなら、安全にハブ部屋へ置いてこられる最初の銃の一つだ。

武器構成を正しく整えれば、バイオハザード0の残りははるかに公平な戦いになる。アイテムボックスのないゲームでは、本当の武器は計画性なのだから。
