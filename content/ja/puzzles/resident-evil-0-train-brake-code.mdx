## バイオハザード0の列車ブレーキパズルとは何なのか

バイオハザード0は1998年7月、アンブレラ所有の豪華列車エクリプティック・エクスプレスの車内から始まる。S.T.A.R.S. ブラヴォーチームの衛生兵レベッカ・チェンバースと、脱獄囚のビリー・コーエンは、まだ死んでいない——あるいはもっと別の何かになっていない——唯一の生存者だ。

列車の章は、ホラーの仮面をかぶったチュートリアルだ。パートナーの切り替え、アイテムを落として後で拾うインベントリシステム（バイオハザード0にはアイテムボックスが存在しないことでも有名だ）、ハーブの調合、そしてゲーム終盤まで頼りになる2人体制の構造を教えてくれる。シリーズ自体の背景については、カプコンの[バイオハザード公式シリーズハブ](https://www.residentevil.com/)が確かな参照先になる。

ブレーキのシークエンスはこの章のクライマックスだ。入力する単一の数字やキーパッドの組み合わせではなく、周囲の手順がすべて完了して初めて機能する短い一連のインタラクションだ。「コード」を検索しているプレイヤーが本当に探しているのは、ブレーキ操作がそもそも反応するようにするための手順の順序なのだ。

| 3 | 車掌室 | 機関車用のキーアイテム | それなしで先へ進まない |

## ブレーキを引く前に：準備チェックリスト

バイオハザード0の列車ブレーキコードで行き詰まるプレイヤーのほとんどは、パズルの問題ではなく準備の問題を抱えている。ブレーキ操作はこの章で最後に触れるべきものであり、早い段階で列車の先頭へ急いでしまうと、ゾンビで埋まった車両を行き来するだけの無駄な時間を過ごすことになる。

運転室は最初のステップではなく、最後のステップとして扱おう。後ろの車両を片付け、すべてを回収し、メモを読み、それから初めて機関車へ向かう。バイオハザード0ではアイテムをどこにでも落として後で拾えるので、片付けた部屋の床は事実上の収納ボックスになる。

実際に時間を節約できる習慣をいくつか挙げる：

- **役割は意図的に分担する。** ビリーは戦闘と重量物を担当し、レベッカはハーブの調合と厳しいアイテム管理を担当する。
- **運転室へ向かうキャラのインベントリは2スロット空けておく。** パズルアイテムは予告なく現れる。
- **メモを取る必要はない。** 必要な情報はゲーム内のファイルに書かれている——それが狙いなのだ。

## バイオハザード0の列車ブレーキコードを順を追って解く

ほとんどのプレイヤーがたどる流れは次のとおりだ。細かい表示はプレイしているバージョンや難易度によって多少変わるが、順序は一貫している。先頭に到達し、条件を満たし、それからブレーキ機構を操作する。

コミュニティの報告では、同じ失敗ポイントが繰り返し語られている——以前の回収を見落としたせいでブレーキ機構が反応しないのだ。もしあなたにそれが起きているなら、同じ操作を繰り返すのではなく、引き返そう。

| ステップ | 行動 | なぜ重要か |
|---|---|---|
| 1 | 先頭までの車両を片付ける | ゾンビが出入口を塞ぎ、回収を妨げる |
| 2 | 車掌室をくまなく回収する | 運転室用のキーアイテムはここにある |
| 3 | 適切なパートナーに切り替える | 戦闘はビリー、インベントリの余裕はレベッカ |
| 4 | 機関車の運転室に入る | ブレーキ操作はここにある |
| 5 | 書類に記された順序でブレーキを操作する | ランダムな入力では機構がリセットされる |
| 6 | ブレーキがかかったことを確認する | 視覚・聴覚の合図を見逃さない |
| 7 | 反応がなければ引き返す | 原因はほぼ見落としたアイテム |

### ブレーキ操作が反応しない理由

運転室までたどり着いたのに、バイオハザード0の列車ブレーキコードパズルがどうしてもうまくいかないなら、何かをリセットする前にこのリストを確認してほしい：

- **書類を読み飛ばしている。** 客車や食堂車にあるメモは飾りではない。手順の理解を左右する鍵だ。
- **キーアイテムを見落としている。** 特定のパートナーとのインタラクションを経て初めて開く部屋に置かれている回収品もある。
- **間違ったキャラクターを使っている。** 一部のオブジェクトは、身体的な強さが意図的なメカニクスであるビリーでしか動かせない、あるいは手が届かない。
- **インベントリが満杯になっている。** 空きスロットがないとパズルアイテムは拾えない——何かを床に落としてからもう一度試そう。

## よくあるミスとプレイヤーが報告する引っかかり

プレイヤーの経験が示すのは、列車の章はエイムの下手さよりもせっかちさを罰するということだ。エクリプティック・エクスプレスのゾンビは動きが遅く予測しやすい。本当の危険は、空っぽだと思い込んだ部屋を通り過ぎてしまうことにある。

| ミス | 何が起きるか | 対処法 |
|---|---|---|
| ファイルを飛ばす | 正しい順序が分からない | 見つけた書類はすべて読む |
| キーアイテムを置き去りにする | 操作が反応しない | 次へ進む前に各車両を2回確認する |
| 1人のキャラに物を溜め込む | パズルアイテムの余地がない | 床落としを収納として使う |
| ハンドガンの弾を浪費する | 運転室への道中で弾が尽きる | 弱い敵はナイフ、追い詰められた時だけ撃つ |
| 先にセーブしない | 列車の章を丸ごとやり直し | 運転室の前にタイプライターでセーブ |
| マップを見ない | 終わらない往復 | 回収のたびにマップを確認する |

もうひとつ見落としやすい点を挙げておく。物語が緊迫していても、ほとんどのプレイヤーは列車のシークエンスに厳しい制限時間はないと感じている。つまり、列車の先頭へ向かう前に、探索し、インベントリを整理し、回復しておく余裕があるのだ。
