## なぜアルバート・ウェスカーは『バイオハザード0』の隠れた原動力なのか

アルバート・ウェスカーは、『バイオハザード0』で起こるすべての惨事の静かなる設計者だ。スペンサー邸でS.T.A.R.S.を裏切るはるか前から、彼はすでに殺人を隠蔽し、アンブレラの研究機構にデータを供給し、自分の部下をウィルス汚染の危険地帯へ送り込んでいる。『バイオハザード0』とウェスカーのつながりは、初回プレイでは見落としやすい。彼はほとんど画面に登場しないからだ——それでも、黄道特急から放棄された訓練施設まで、その指紋は物語全体に残っている。

## 『バイオハザード0』の物語におけるウェスカーの役割

『バイオハザード0』は1998年7月、洋館事件の数時間前を舞台にする。S.T.A.R.S.ブラヴォチーム最年少のレベッカ・チェンバースは、部隊が壊滅した後、黄道特急と呼ばれる豪華列車に取り残される。彼女は脱獄囚ビリー・コーエンと手を組み、アンブレラが所有するヒルがはびこる施設を戦い抜く。

ブラヴォチームをその状況に追い込んだのはウェスカーだ。隊長として、彼はアークレイ山地への派遣を承認した。部下たちが知らないのは、彼がアンブレラの工作員であり、その忠誠は常に会社に、そして最終的には自分自身にあったということだ。

### すべての始まりとなった1988年の暗殺

本作で最も重要なウェスカーのシーンはフラッシュバックだ。アウトブレイクの約10年前、ウェスカーと研究者ウィリアム・バーキンは、オズウェル・E・スペンサーの命令で、アンブレラの創設科学者の一人ジェームズ・マーカスを暗殺した。マーカスの遺体は施設の処理システムに捨てられた。

その隠蔽工作はもたなかった。マーカスの遺体はヒルをベースにした生物に取り込まれ、10年後、復活したマーカスは復讐として黄道特急内と訓練施設内でt-ウィルスを解き放った。言い換えれば、レベッカが戦い抜くアウトブレイクは、ウェスカーとバーキンが問題を葬り去ったと思い込んだことによって存在する。

### ウェスカーが画面上で実際に行うこと

『バイオハザード0』でのウェスカーの出番は限られているが、その登場はすべて重要な意味を持つ：

| 物語のポイント | 起こる場所 | 重要な理由 |
|---|---|---|
| マーカス暗殺のフラッシュバック | アンブレラ訓練施設（過去） | ウェスカーが単なる官僚ではなく殺し屋であることを確立する |
| ブラヴォチームの派遣 | アークレイ山地 | レベッカをアウトブレイクの直中に置く |
| バーキンとの連絡 | 施設と研究室エリア | 救助ではなく戦闘データが優先事項であることを明かす |
| 終盤の会話 | 施設陥落後 | 初代『バイオハザード』の敵役としての役割を準備する |

重要なのはその姿勢だ。ウェスカーは決して慌てない。彼は自分のチームの死を許容できる研究コストとして扱う。まさにその思考が、後の時系列でS.T.A.R.S.を洋館へ誘い込むときに実を結ぶ。

## ウェスカーモード：HDリマスターで悪役を操作する

2002年のゲームキューブ版オリジナルではウェスカーを操作できなかった。それが変わったのは2016年のHDリマスターで、ビリー・コーエンをアルバート・ウェスカーに置き換えるボーナスシナリオが追加された。物語を変えない非正史の「if」シナリオだが、非常に楽しく、本編と比べて本格的な無双感がある。

### ウェスカーモードの解放方法

1. メインキャンペーンを一度クリアする。難易度は解放に関係しない。
2. クリア済みファイルを保存し、メインメニューに戻る。
3. モード一覧からウェスカーモードを選ぶ。通常のストーリーとは別枠だ。
4. 難易度を選び、ウェスカーをレベッカのパートナーとして新規プレイを開始する。

解放は一度のクリアに紐づいているため、最速ルートはまず通常どおりストーリーをプレイし、その後ウェスカーモードで再プレイすることだ。ボーナスモードを解放するためだけに高難易度で本編を急いで進めようとするのは、たいてい裏目に出る。列車パートは新規プレイヤーに容赦がないからだ。

### ウェスカーの能力

ウェスカーの操作感はビリーとはまったく違う。コミュニティの報告では、彼はより速く、よりタフで、はるかに攻撃的なパートナーキャラクターだと一貫して評されている。

| 能力 | 効果 | 最適な使い方 |
|---|---|---|
| ウェスカーチャージ（ダッシュ） | 前方への素早い急加速 | 群れからの脱出、位置取り、距離を詰める |
| 強力な近接攻撃 | 壊滅的な近距離攻撃 | ひるんだ敵のとどめ、弾薬節約 |
| 耐久力上昇 | ビリーより多くのダメージに耐える | 狭い通路で攻撃を受け止める |
| 標準の銃火器 | ビリーと同じ武器を使う | その他すべて |

プレイヤー体験によれば、ダッシュが最もゲームを変える能力だ。ビリーなら戦うかゆっくり逃げるしかない場所でも、敵を完全に飛ばして通り抜けられるため、バックトラックのルートを劇的に短縮できる。

## 『バイオハザード0』のウェスカーが大きな時系列にどう位置づけられるか

『バイオハザード0』はウェスカーの長期的な陰謀の最初の章だ。ここで彼を見ると、その後の登場の読まれ方が変わる。陰謀がどれほど早く始まっていたかを理解できるからだ。

| ゲーム | ウェスカーの役割 |
|---|---|
| バイオハザード0 | アンブレラの二重スパイ；マーカス暗殺を隠蔽 |
| バイオハザード（1996 / 2002） | S.T.A.R.S.を裏切り、死を偽装し、タイラントのデータを持ち去る |
| バイオハザード コード：ベロニカ | 超人的な敵役として復帰 |
| バイオハザード4 | 裏で活動し、エイダ・ウォンに情報を提供 |
| バイオハザード5 | ウロボロス計画を掲げる主要な敵役 |

時系列順にプレイすると、『バイオハザード0』のウェスカー関連内容は、すでに来ると分かっている裏切りのプロローグとして機能する。その劇的皮肉こそ、初代をクリアした後に前日譚を再訪する価値がある主な理由だ。

## 『バイオハザード0』のウェスカー関連コンテンツを最大限楽しむコツ

- **まずストーリーモードをプレイする。** ウェスカーのカットシーンは少ないため、メインキャンペーンを一度見ていないと物語が理解しづらい。
- **ウェスカーモードはご褒美の周回と考える。** 本編より簡単なので、サバイバル技術を試すのではなく、実績回収に使おう。
- **レベッカを生かしておく。** 彼女は依然としてコンビの脆い側であり、ウェスカーがどれほど強くても彼女を失えばそのプレイは終了する。
- **ダッシュは戦闘を始めるためではなく、戦闘を飛ばすために使う。** 序盤に弾薬を節約すると、研究室パートのストレスが大幅に減る。
- **アイテムは一元的に管理する。** 『バイオハザード0』ではアイテムボックスが廃止されているため、予備の物資は再訪する部屋に置いておく。
- **物語の変化は期待しない。** ウェスカーモードはボーナスシナリオであり、正史を書き換えるものではない。
- **オリジンズ コレクションを確認する。** 『バイオハザード0』と初代の2002年リメイクの両方が欲しいなら、通常はバンドルの方がお得だ。

## FAQ

**ウェスカーは『バイオハザード0』で操作できますか？**
操作できるのは、2016年のHDリマスターで追加されたボーナスシナリオ、ウェスカーモードだけです。正史のストーリーキャンペーンでは操作できず、そこではビリー・コーエンがレベッカのパートナーのままです。

**なぜウェスカーは『バイオハザード0』にあまり登場しないのですか？**
本作はレベッカとビリーに焦点を当てています。ウェスカーは意図的に背景に置かれ、マーカス隠蔽の黒幕としての役割がスポットライトではなく、啓示として響くようになっています。

**ウェスカーモードはどうやって解放しますか？**
任意の難易度でメインキャンペーンを一度クリアし、クリア済みセーブファイルでメインメニューからウェスカーモードを選択してください。

**ウェスカーモードは『バイオハザード0』のウェスカーの物語を変えますか？**
いいえ。非正史のボーナスシナリオです。カットシーンや出来事は同じままで、操作可能なパートナーキャラクターだけが変わります。

**ウェスカーモードは本編より簡単ですか？**
概してはい。彼のダッシュと強力な近接攻撃により、本来ならリソースを消耗する敵を回避したり殲滅したりできるため、多くのプレイヤーが回収目的の周回に使うのもまさにそのためです。

## 最後に

ウェスカーは『バイオハザード0』の主役ではないが、物語が起こる理由そのものだ。彼が数年前に行った一度の暗殺が、レベッカとビリーが生き延びるアウトブレイクを生み、惨事が展開するのを冷静に見つめる姿は、彼がなる男のすべてを物語っている。まず物語のためにキャンペーンを一度プレイし、その後ウェスカーモードを起動して、シリーズで最も計算高い悪役を操作する貴重な機会を楽しもう。
