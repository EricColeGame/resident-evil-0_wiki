黄道特急は、バイオハザード0が雰囲気重視の作品からプレイヤーを試す作品へと変わる場所だ。このバイオハザード0攻略列車ガイドでは、ゲーム冒頭チャプターのすべてを扱う——感染した客車、リーチがはびこる通路、列車の先頭へ進む道を塞ぐアクセスパズル、そしてアンブレラの庭先へと放り出す脱線事故まで。ここでつまずけば、弾薬もハーブもなく、到達できない通路に相棒を置き去りにしたまま、その後数時間を足を引きずって進むことになる。ここを正しく突破すれば、バイオハザード0の列車シーケンスが、なぜクラシック・サバイバルホラーのなかでも屈指の厳しい序盤であり続けているのか分かるはずだ。

列車チャプターは空間が狭く、影響は長く続く。ショップもアイテムボックスもなく、逃げられる場所もごく少ない。最初の1時間で下すあらゆる決断が、ゲームの残り全体に響く。

## なぜ黄道特急はクラシック『バイオハザード』で最も厳しい序盤なのか

バイオハザード0は2002年にゲームキューブで最初に発売され、2016年には現代向けプラットフォームでHDリマスターとして復活した。いずれにせよ、物語は1998年7月、洋館事件の数日前に始まる。18歳のS.T.A.R.S.ブラボーチーム衛生兵、レベッカ・チェンバースが、アークレイ山地で停止したアンブレラの豪華列車に乗り込むのだ。彼女はひとり、軽装備で、乗客たちはすでに死亡しているか、変わり始めている。

この列車がこれほど過酷なのは、その構造にある。黄道特急は狭い通路の連続で、掴みかかられても簡単に回り込めない。ドアは敵から逃がしてくれるどころか、敵のいる方へと誘い込む。さらに、リソースを2つのインベントリに分割するパートナーシステムが加わることで、物資の溜め込みもパニックも等しく罰するチャプターになる。

| チャプター詳細 | プレイに与える意味 |
| --- | --- |
| 舞台 | アンブレラの黄道特急、アークレイ山地、1998年7月 |
| 操作可能キャラクター | レベッカ・チェンバースとビリー・コーエン、いつでも切り替え可能 |
| 保管 | アイテムボックスなし——置いたアイテムはその部屋に残る |
| セーブシステム | 標準難易度ではインクリボンが限られたタイプライター |
| 資源密度 | 弾薬は少なめ、ハーブはほどほど、序盤の回復アイテムはごくわずか |
| 最大の失敗ポイント | 普通の乗客ゾンビにショットガンや強力な弾薬を使ってしまう |

## まず習得すべきパートナーザッピングとインベントリのルール

バイオハザード0の代名詞的メカニクスはパートナーザッピングだ。2人のキャラクターを操作し、瞬時に切り替えられ、置き去りにした方はAIが担当する。列車は、認めているかどうかに関わらず、このチュートリアルになっている。片方が位置をキープしている間に、もう片方が車両を漁れる。そして絶妙なタイミングでの切り替えは、見えなかった掴みからあなたを救う。

AIパートナーは戦闘の天才ではない。ゾンビのいる部屋にひとりで放置すれば、パートナーは攻撃を受ける。実践的なルールはこうだ。敵が届く場所にキャラクターを待機させないこと、そして自分と唯一の出口の間にキャラクターを立たせたままにしないこと。

### アイテムドロップシステムがアイテムボックスを置き換える

バイオハザード0にはアイテムボックスがないため、実質的に床がインベントリになる。落としたものは落ちた場所にそのまま残る。つまり、何度も行き来する部屋に補給用の隠し場所を作れる——食堂車や中央の客車が理想的だ。ただし、チャプターの最後に列車は破壊されるので、脱線事故のときに置き去りにしたものは永久に失われることを忘れないように。

| キャラクター | 長所 | 列車での最適な役割 |
| --- | --- | --- |
| レベッカ・チェンバース | ハーブ調合、アイテム合成、支援役 | すべてのハーブ、調合済み回復アイテム、パズルアイテムを持つ |
| ビリー・コーエン | 体力が多く、ダメージに強い、前線の戦闘役 | メイン武器と予備弾薬を持ち、通路の先頭に立つ |

## バイオハザード0攻略 列車ルート：フェーズ別目標

正確なパズル手順は、どれだけ徹底的に探索するかによって変わるが、チャプターは常に同じ大きな流れをたどる。以下の表は厳密な台本ではなく、ルートマップとして扱ってほしい。

| フェーズ | 主な目標 | 注意点 |
| --- | --- | --- |
| 1. 乗車 | 後部客車を探索し、ドロップシステムを学ぶ | 狭い通路の乗客ゾンビ。倒れた死体に弾薬を無駄にしない |
| 2. 初遭遇 | ビリー・コーエンと出会い、協力に合意する | スクリプトシーン——発生前にハンドガンを装填しておく |
| 3. 協力 | ビリーを解放し、装備を2つのインベントリに分ける | 単独操作を失う。武器は意図的に割り振る |
| 4. 物資回収 | 客車と食堂車を掃討し、鍵、弾薬、ハーブを集める | インベントリ満杯——捨てずに置く |
| 5. アクセスパズル | 先頭へ向かう道を開く現地の仕掛けを解く | リーチの待ち伏せと長いバックトラック |
| 6. 後部車両 | 列車後部を占拠したリーチ生物を生き延びる | 資源の消耗が激しい。両キャラクターを回復させておく |
| 7. ブレーキと脱線 | 制御装置に到達し、脱線を耐え抜き、移行を生き延びる | 最後のスクリプトシーケンス。未回収アイテムは失われる |

いくつかの習慣で、7つのフェーズすべてが楽になる：

- カットシーンらしきものを発生させる前に、車両を完全に掃討する。スクリプトの場面は、背後でドアをロックすることがよくある。
- レベッカのインベントリは軽く保ち、その場でパズルアイテムを拾える余裕を残す。
- パンくずの道しるべを残す：予備弾薬と回復アイテムは、行き止まりの個室ではなく、最も頻繁に通る車両に置く。
- ドアを開ける前にリロードする。RE0のゾンビは戸口での掴みが大好きだ。

## 列車の敵、ハーブ調合、弾薬の節約

列車の敵の顔ぶれは少ないが、効率的だ。感染した乗客と乗員、じっとしていることを罰するリーチの群れ、そしてチャプター終盤には多くのプレイヤーがゲーム最初の本物の腕試しと見なす大型リーチ生物と対峙する。コミュニティの報告では、準備不足のプレイが崩壊するポイントとして、この戦いが一貫して挙げられている。

| 敵 | 遭遇場所 | 脅威度 | 最善の対処 |
| --- | --- | --- | --- |
| 感染した乗客 | 客車、食堂車 | 中 | ハンドガンで頭を狙う。倒れた敵は止めを刺さずに通り過ぎる |
| リーチの群れ | 通路と後部区画 | 高 | 距離を取り、近接範囲を避け、使える中で最強の武器を使う |
| 大型リーチ生物 | 列車後部 | ボス級 | 両キャラクターを全快にし、強力な武器を装填し、無駄弾を撃たない |
| 環境 | 狭い通路、ドア、狭い角 | 常時 | 撃つ前に下がる。パートナーを戸口に立たせない |

### ハーブ調合の基本

このコンビでハーブを調合するのはレベッカなので、グリーン、レッド、ブルーのハーブはすべて彼女のインベントリに入れよう。戦闘前に調合しておく方が、戦闘中に回復するよりもほぼ常に良い。調合済みハーブは1回の行動で使え、個々の合計よりも多く回復するからだ。

| 組み合わせ | 効果 |
| --- | --- |
| グリーン | 少量の体力回復 |
| グリーン + グリーン | 中程度の体力回復 |
| グリーン + グリーン + グリーン | 大量の体力回復 |
| グリーン + レッド | 体力全回復 |
| グリーン + ブルー | 体力回復＋毒治療 |
| グリーン + レッド + ブルー | 体力全回復＋毒治療 |

弾薬の節約も同じくらい重要だ。列車ではハンドガンが基本の答えであり、それより強力なものはリーチとの遭遇と後部車両の戦いのために取っておくべきだ。通路のゾンビを回り込んでやり過ごせるなら、そうしよう。

## 難易度、インクリボン、HDリマスターの違い

2016年のリマスターはオリジナルの構造を保ちつつ、現代的な便利さを追加しているが、列車チャプターは相変わらず難易度のフィルターであり続けている。標準難易度ではセーブに依然としてインクリボンを消費するので、各タイプライターはチェックポイントではなく資源として扱おう。

| 設定 | 変更点 |
| --- | --- |
| イージー | ダメージが寛容で資源も多め。初めてストーリーを進めるのに良い |
| ノーマル | 意図された体験。インクリボンも弾薬も厳しく感じる |
| ハード | 敵のダメージが容赦なく、物資も乏しい。すべての遭遇を計画する |
| ウェスカー・モード | ゲームクリア後に解放。まったく異なるパワーファンタジー |
| リーチハンター | クリア後に解放されるボーナスミニゲーム。純粋なスコアアタック挑戦 |

リマスターをプレイするなら、購入前にカプコンの公式バイオハザードシリーズサイトで対応プラットフォームとバージョン詳細を確認しよう。このゲームは何世代ものハードウェアで発売されているからだ。

初めてのプレイスルーなら、ノーマルが正解だ。イージーは悪い癖——とくに、何でも撃つ癖——を教えてしまう。そして列車は、その教訓を学ぶのに最悪の場所だ。

## FAQ：バイオハザード0攻略 列車に関する質問

**バイオハザード0攻略の列車パートはどれくらい時間がかかる？**
コミュニティの報告では、慎重な初回プレイは約1時間以上かかる。どれだけ探索するか、置いたアイテムを取りにどれだけ戻るかによる。ルートとパズルの解答を知っている経験者は、はるかに速く進む。

**黄道特急をスキップできる？**
いいえ。バイオハザード0の必須の冒頭チャプターであり、そこで集めたアイテムはそのまま続くアンブレラ施設へ持ち越される。後で解放できる列車関連のコンテンツは、リーチハンターやウェスカー・モードのようなボーナス素材だけだ。

**ハーブはビリーとレベッカのどちらが持つべき？**
レベッカ。彼女はハーブをより強力な回復アイテムに調合でき、実質的な体力も少ないので、回復手段を彼女に持たせる方が安全だ。ビリーには武器、弾薬、そして力が必要なものを持たせよう。

**列車で置いたアイテムは消える？**
列車にいる間は、置いた部屋にそのまま残る。ただし、チャプターの脱線シーケンスが進むと、置き去りにしたものはすべて消える——だからチャプター終盤に進む前に、最後の掃討を行おう。

列車をマスターすれば、バイオハザード0の残りは実際に勝てる資源管理ゲームになる。ここで失敗すれば、外さない敵であふれた施設で、ハンドガンの弾を必死に探してその後数時間を過ごすことになる。落ち着いて、装備を意図をもって分割し、黄道特急での一発一発を、最後の弾だと思って扱おう——しばらくの間、本当にそうなるかもしれないのだから。
