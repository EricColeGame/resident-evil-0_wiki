荷造りのいい加減さをここまで厳しく罰するサバイバルホラーは、そう多くない。『バイオハザード0』はまさにその典型だ。ゲームキューブ向けの前日譚として登場し、後に現代のプラットフォーム向けにリマスターされた本作は、シリーズを象徴してきたアイテムボックスを廃止し、はるかに奇妙な仕組みへと置き換えた。それが、自分が去った後の部屋にそのまま残る「バイオハザード0のアイテム管理」である。初めてプレイする人にとって、このシステムは今にも作動しそうな罠のように感じられるだろう。だが一度コツをつかめば、本作で最も頭の切れるパズルへと変わり、20年経った今もベテランプレイヤーが議論を続ける理由にもなっている。

## バイオハザード0のアイテム管理システムの仕組み

『バイオハザード0』では操作可能なキャラクターが2人おり、所持容量は2人で分担される。レベッカ・チェンバースとビリー・コーエンはそれぞれ6つのアイテムスロットを持ち、合計12スロットとなる。太っ腹に思えるが、落とし穴がある。ショットガン、鍵、グリーンハーブ、弾薬の箱——どんなアイテムでも、スロットをちょうど1つ消費するのだ。ここにはサイズのグリッドもなく、1996年の初代のようなテトリス式の荷詰めも存在しない。

さらに大きな変更は、アイテムボックスの扱いだ。『バイオハザード0』は、本編シリーズからアイテムボックスを初めて、そして唯一の例として完全に排除した。代わりに、今いる部屋の床にアイテムを自由にドロップでき、それはその周回の間ずっとそこに残る。敵に盗まれることもない。カットシーンを挟んでも消えることはない。倉庫そのものがマップなのだ。

レベッカとビリーが同じ部屋にいるなら、何もドロップする必要はない。アイテム画面を開き、「Exchange（交換）」コマンドを使えば、2人の間で直接アイテムを移動できる。鍵アイテムを渡したり、銃を撃つ側に弾薬を回したりする最速の方法だ。

| 機能 | クラシック『バイオハザード』（RE1/RE2スタイル） | 『バイオハザード0』 |
|---|---|---|
| 保管場所 | セーブルームのアイテムボックス | アイテムボックスは一切なし |
| 容量 | 共有ボックスで実質無制限 | キャラごとに6スロット、合計12 |
| アイテムサイズ | 1～2以上のグリッドを占有 | すべてのアイテムがちょうど1スロット |
| アイテムの移動 | ボックスに出し入れ | どこでも床にドロップ |
| キャラ間の受け渡し | 該当なし（主人公は1人） | 同じ部屋にいるときにExchangeで交換 |
| 管理方法 | ボックスの中身リスト | マップがドロップ品のある部屋を表示 |
| 主なリスク | ボックスに何を入れたか忘れる | *どこに*ドロップしたかを忘れる |

その他の仕様はすべてこの2つのルールから導かれる。ドロップが永続的だからこそ、賢いプレイヤーはキャッシュ（隠し場所）を構築する。予備の弾薬、回復アイテム、パズル用のツールを、再び通ると分かっている部屋にまとめて置いておくのだ。

## レベッカ vs. ビリー：『バイオハザード0』のアイテムをどう分担するか

誰が何を持つかは、シリーズのどの作品よりも重要だ。ビリーは戦闘要員であり、より多くのダメージに耐えられる。ハンターが現れたとき、ショットガンを握っていてほしいのは彼だ。レベッカはパズルの解き手であり衛生兵でもあるが、鍵だけを持たされて放置されれば、あっという間に倒れてしまう。

こうして役割分担が明確になる。コミュニティの報告でも、同じ分担に落ち着くことが多い。

| 役割 | レベッカ | ビリー |
|---|---|---|
| 得意分野 | 回復アイテム、鍵アイテム、パズル用ツール | 武器、弾薬、強力な火力 |
| 初期武器 | ハンドガン | ハンドガン |
| 耐久力 | 低い — 彼女を守れ | 高い — 打たれ強い |
| 推奨スロット配分 | 回復2、鍵2、武器1、空き1 | 武器2、弾薬3、空き1 |
| 理由 | 端末や装置を操作するのはたいてい彼女 | 攻撃を受け、部屋を片付けるのは彼 |

各キャラクターに「空きスロット1つ」というのは、あくまで提案ではない。柔軟性を完全にゼロにすると、鍵アイテムを見つけた瞬間に、ドロップして取りに戻るという遠回りを強いられる。キャラごとに予備スロットを1つ確保しておけば、そのほとんどを防げる。

良い習慣を一つ。部屋を片付け、後でまた通ると分かっているなら、今すぐ必要でないものはすべて置いていこう。身軽に歩き、身軽に戦うのだ。

## 持ち歩くもの、置いていくもの

新規プレイヤーが犯す最大のミスは、『バイオハザード0』のアイテム管理を物流網ではなくバックパックのように扱ってしまうことだ。すべてを持ち歩く必要はない。正しいものだけを持ち、残りは置いておくべきなのだ。

| アイテムの種類 | 持ち歩く？置く？ | 理由 |
|---|---|---|
| グリーン・レッド・ブルーハーブ | 持ち歩き、すぐ調合 | 調合すれば2～3スロットを1つに圧縮できる |
| 救急スプレー | キャッシュに置く | 1スロットで全回復できるが、常に手元に必要になることは少ない |
| ハンドガンの弾 | ビリーに持たせる | 最も入手しやすい弾薬で、彼の武器をいつでも使える状態に保てる |
| ショットガン／グレネードランチャー | 片方を持ち、もう片方は置く | 重火器は鍵アイテムに必要なスロットを食いつぶす |
| 鍵アイテムとツール | 使うまで持ち、その後ドロップ | 多くは使い捨て — 無駄な重りを運ぶな |
| インクリボン | タイプライターの近くに置く | セーブポイントでしか必要にならない |
| フックショット | 次に必要になる場所に置く | 典型的なスロット食い。何時間もスロットを1つ占有しかねない |

ハーブの調合については、独立した段落を割く価値がある。ハーブ2つはスロット2つを消費する。1つの調合ハーブにまとめれば1スロットで済む。素材が揃った瞬間に調合しよう。後回しにしてはいけない。遅らせた1分は、無駄なスロットを抱えて歩く1分に等しい。グリーンとレッドを混ぜれば回復量が上がり、3種ミックスならダメージと毒を1つのアイテムで同時に対処できる。

## 『バイオハザード0』のアイテム管理でよくあるミス

プレイヤーが報告するストレスの多くは、4つか5つの繰り返しがちなミスに由来する。どれも2周目なら修正可能だし、今プレイ中ならその場で直せる。

| ミス | 失うもの | 対処法 |
|---|---|---|
| エクリプティック急行に装備を置き忘れる | それらは永久に失われる | 列車パートが終わる前に整理せよ。列車は一方通行だ |
| フックショットをどこへでも持ち歩く | 何時間も1スロットが塞がる | 最後に使った場所に置き、戻る途中で回収する |
| 「ラスボス用」に弾薬を溜め込む | スロットの無駄遣い、そして中盤戦が厳しくなる | 見つけた分は使え。ハンドガンの弾は十分に手に入る |
| すべてを片方のキャラに持たせる | いざというときもう片方に回復がない | 回復アイテムは2人で分け合う |
| Exchangeをまったく使わない | ドロップと拾い直しの無限ループ | 2人が同じ部屋にいるなら、いつでも直接交換する |
| 慌ててアイテムをドロップする | どこに置いたか忘れる | 先へ進む前に、マップのドロップ品マーカーを確認する |

列車の警告は、そのまま周回が終わる案件だ。序盤エリアを離れたら、戻る道はない。列車の床に置いたものは永遠にそこに残る。降りる前に装備を整理しよう。

## 『バイオハザード0』アイテム管理の上級テクニック

基本が身につけば、『バイオハザード0』のアイテム管理は不安の種ではなく、ルート設計のツールになる。以下は経験豊富なプレイヤーやRTA走者から出たアプローチだ。

| 状況 | アイテム管理のアプローチ | 備考 |
|---|---|---|
| 通常のストーリー攻略 | 携帯用キット2つ＋キャッシュ3～4か所 | セーブルームやメインホール付近にキャッシュを置く |
| ボス戦 | 直前の部屋に弾薬と回復を事前配置 | 戦闘中のメニュー操作でパニックになるのを避ける |
| リーチハンター | すべてのスロットを貴重品として扱う | このミニゲームはドロップ＆キャッシュ思考の純粋なストレステストだ |
| ウェスカーモード | ウェスカーの機動力に頼る | 彼はビリーと入れ替わり、どれだけ攻められるかが変わる |
| RTA（スピードラン） | すべてのドロップを台本化する | 走者は部屋単位で拾得物まで計画する |

地味に役立つ仕様が2つある。1つ目は、アイテム画面で両キャラのスロットが並んで表示されるため、部屋に入る前に受け渡しを計画できること。2つ目は、ドロップしたアイテムがマップに表示され、取り戻しの作業が当てずっぽうからチェックリストに変わることだ。

リマスター版がどのプラットフォームで遊べるか確認したいなら、カプコンの[バイオハザード公式ポータル](https://www.residentevil.com/)から始めるのがよい。それ以外については、基本ルールは変わらない。持ち歩く量を減らし、置く量を増やし、自分の物がどこにあるかを常に把握しておこう。

## FAQ

**『バイオハザード0』にアイテムボックスはありますか？**
いいえ。『バイオハザード0』は、本編シリーズで唯一アイテムボックスを完全に廃止した作品です。アイテムの保管は床に置くことで行い、置いたアイテムはゲーム終盤までそこに残ります。

**各キャラクターのスロット数はいくつですか？**
レベッカとビリーはそれぞれ6個のアイテムを所持でき、2人合わせて12個となります。種類や大きさに関係なく、どのアイテムもちょうど1スロットを消費します。

**ドロップしたアイテムを失うことはありますか？**
戻れなくなるエリアでのみ失われます。特に序盤のエクリプティック急行のシーケンスが代表的です。それ以外の場所では、置いた装備は置いた場所にそのまま残ります。

**レベッカとビリーは直接アイテムを交換できますか？**
はい。2人が同じ部屋にいるときにアイテム画面を開き、Exchangeを使えば、即座にアイテムを移動できます。ドロップは不要です。この1つのコマンドを使いこなせるかどうかが、快適な『バイオハザード0』のアイテム管理と、延々と往復し続ける苦行とを分ける分かれ目です。
