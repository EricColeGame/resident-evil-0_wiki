サバイバルホラーにおいて、『バイオハザード0』のグラップリングガンほど、静かな苛立ちを招いてきたものは少ない。『バイオハザード0』のフックショットは武器ではなくキーアイテムだ。峡谷の向こうへ鉤付きのロープを発射して渡れるようにするもので、敵にダメージを与えることは一切ない。それでも、これなしでキャンペーンをクリアすることはできない。『バイオハザード0』のフックショットがどこで手に入り、ゲームがいつ携帯を想定しているのか、そして狭いインベントリにどう押し込むかを理解しているかどうかが、クリーンな攻略と、モンスターだらけの廊下を1時間もバックトラックする差を生む。

本ガイドでは、このアイテムの役割、ドロップ＆スワップ方式のインベントリシステムが携帯方法をどう変えるか、初見プレイヤーがつまずくミスを扱う。

## フックショットとは実際何なのか

フックショットはグラップリングガン、つまり固定されたアンカーポイントへ鉤付きロープを発射するランチャーだ。正しい場所に立ち、装備すると、キャラクターがロープを発射し、アンカーに引っかけ、自らを引っ張って溝を渡る。シリーズでも最も純粋な「パズルアイテム」設計の一つで、戦闘ではなく地形を解決するために存在する。

拾う前に押さえておきたい特徴がいくつかある。

- **武器ではなくキーアイテム。** ダメージはゼロで、敵に狙いを定めることもできない。
- **指定されたアンカーポイントでしか使えない。** 任意の壁や天井に自由に狙って撃つことはできない。
- **進行に必須。** 特定の場所はこれなしでは渡れない。
- **インベントリの物理スペースを占有する。** かさばるアイテムであり、『バイオハザード0』で最も乏しい資源はスペースだ。

| 項目 | 詳細 |
|---|---|
| アイテム分類 | キーアイテム（移動用ツール） |
| 戦闘用途 | なし — ダメージを与えない |
| 弾薬タイプ | 該当なし |
| インベントリ消費 | 2スロット（プレイヤー報告） |
| 入手場所 | 養成所内 |
| 携帯可能者 | レベッカまたはビリーのどちらでも |
| パートナー間の受け渡し | 可能（落として拾わせる） |
| クリアに必須 | はい — 特定の溝で必要 |
| 完全に捨てられるか | 避けること。必須アイテムとして扱う |

## 入手場所と必要なタイミング

フックショットは、黄道特急でのシークエンス後、キャンペーンで2番目の主要エリアである養成所内で見つかる。養成所を探索中に入手でき、レベルデザインは親切だ。通常、越えられない溝を先に見せてから、それを解決するツールを渡してくれる。

それ以降、フックショットは物語の残りを通して装備品の一部となる。後に、フックショットのロープでしか先へ進めない場所が少数ある。まさにそれゆえ、多くのプレイヤーが詰まる。「後で使う」つもりで適当な部屋に落とし、3エリア後に必要になるのは、このゲームのコミュニティで最もよく聞く不満の一つだ。

『バイオハザード0』にはアイテムボックスがないため、床が倉庫になる。落としたものはその部屋に残る。その一つの設計判断が、単純な移動ツールをインベントリ管理の問題に変えている。

| 状況 | あなたにとっての意味 |
|---|---|
| 広い溝に初めて遭遇 | 操作中のキャラクターのインベントリにフックショットが必要 |
| 以前のエリアを再訪 | 再び渡るには通常またこのアイテムが必要 |
| 物語後半の峡谷 | 2度目の必須使用。不要になったと決めつけない |
| パートナーを置き去り | キャラクターを切り替えて同じ渡河を繰り返す |
| 遠い部屋にアイテムを落とした | 実際に歩いて戻り、回収しなければならない |

## フックショットの使い方：手順ごとに

パターンさえ分かればフックショットの使用は簡単だが、ゲームは明確に説明してくれない。基本の流れはいつも同じだ。

| 手順 | 操作 |
|---|---|
| 1 | 現在操作しているキャラクターのインベントリにフックショットがあるか確認する |
| 2 | 溝の端、または発射位置のマーカーまで歩く |
| 3 | インベントリメニューからフックショットを装備する |
| 4 | アンカーポイントに向けて狙う — 有効なターゲットがハイライトされる |
| 5 | ロープを発射する。キャラクターが引っかかり、自動で渡る |
| 6 | パートナーがついてきたか確認する。来ていなければ切り替えて手動で渡らせる |

実用的な注意が2つ。1つ目、アンカーポイントがハイライトされない場合、立っている場所が間違っている。縁に沿って1、2歩動いてみよう。2つ目、パートナーのAIが端で止まってしまったら、キャラクターを切り替えて直接渡らせる。AIが自力で解決するのを待つより速い。

## インベントリ管理：本当の難所

『バイオハザード0』では、2人のプレイアブルキャラクターそれぞれに6スロットのインベントリが与えられる。アイテムボックスも、共有ストレージも、容量拡張手段もない。したがって2スロットのフックショットは、片方のキャラクターの全携帯容量の3分の1を消費する。常に持つなら、それは永続的だ。

このトレードオフこそ、フックショットの評判の核心だ。使いにくいアイテムではない。*持ち運ぶ*のが難しいアイテムなのだ。

| アイテム | おおよそのスロット | 備考 |
|---|---|---|
| フックショット | 2 | 問題のアイテム。かさばり、状況依存 |
| ハンドガン | 1 | 軽く、常に携帯する価値がある |
| ショットガン | 2 | 重いが、近距離の脅威には必須 |
| ハーブ（各） | 1 | 調合でスペースを節約できる。調合はレベッカのみ |
| 救急スプレー | 1 | 即時全回復。調合不要 |
| 弾薬（各タイプ） | 1 | 発射するたびに束が消費される |

**レベッカ vs. ビリー：誰に持たせるべき？**

| 要素 | レベッカ | ビリー |
|---|---|---|
| インベントリスロット | 6 | 6 |
| ハーブ調合 | 可能 — 効率的にハーブを組み合わせる | 不可 |
| 戦闘での耐久力 | 低い | 高い |
| 一般的な役割 | サポート、パズル解決、回復 | 前線戦闘と重量物の運搬 |
| 一般的なおすすめ | ビリーを操作する頻度が高いなら彼に持たせる | レベッカにハーブ用の空きスロットが必要なら彼女に持たせる |

プレイヤーの経験則では、空き2スロット分があり、かつ戦闘で積極的に操作していないほうのキャラクターにフックショットを持たせるのが一般的に有利だ。ただし、即座に手渡すことはできない。落として、もう一方のキャラクターに拾わせる必要がある。

## 何時間も無駄にするよくあるミス

フックショットに関する問題のほとんどは自分で招くものだが、すべて避けられる。

| ミス | なぜ痛いか | より良い方法 |
|---|---|---|
| 再訪しにくい部屋に落とす | 長く危険なバックトラックを強いられる | 置いた部屋をメモする |
| 武器として扱う | 敵に狙いを付ける時間を無駄にする | 代わりに銃器へ切り替える |
| 全スロットを銃と弾薬で埋める | 2スロットのアイテムを入れる余裕がなくなる | どちらかのインベントリに2スロット分の空きを確保する |
| 渡らないほうのパートナーに持たせたままにする | 渡河がそもそも起こらない | キャラクターを切り替えて装備し直す |
| ゲーム後半には不要になると決めつける | 後の峡谷で立ち往生する | キャンペーン終了まで保持する |
| 端でパートナーを忘れる | 渡河中に置き去りにされることがある | 先へ進む前にパートナーを確認する |

もう一つ身につけたい習慣がある。どの部屋を出る前にもインベントリを確認し、フックショットが必要な場所にあるか自問することだ。アイテムボックスのないゲームでは、「自分の荷物はどこだ？」が本物のゲームメカニクスなのだ。

## 周回プレイとスピードラン向けのコツ

キャンペーンを覚えてしまえば、フックショットはパズルからルート取りの問題へと変わる。

- **携帯する期間を計画する。** コミュニティのスピードランナーはフックショットを一時的な乗客として扱う。拾い、使い、必要な渡河が終わったらすぐ手放す。
- **戻る用事と組み合わせる。** 回収のために戻らなければならないなら、別の目的ですでにそちらへ向かうついでに行う。
- **ハーブはレベッカ、銃はビリーに。** この分担なら、かさばるアイテム用の空きスペースを予測しやすくなる。
- **パートナーの渡河を練習する。** 縁でのスムーズなキャラクター切り替えは、1回ごとに数秒を節約する。
- **溜め込まない。** 使っていない弾薬は、キーアイテムに使えるはずのスロットだ。

ゲーム本体の公式詳細については、カプコンの[バイオハザードシリーズポータル](https://www.residentevil.com/)がリリースと対応プラットフォームに関する最も信頼できる参照先だ。

## よくある質問

**『バイオハザード0』のフックショットは武器として使えますか？**
いいえ。ダメージはなく、敵に狙いを定めることもできません。指定されたアンカーポイントでの移動専用です。

**『バイオハザード0』のフックショットはどこで手に入りますか？**
列車のシークエンス後、ゲームで2番目の主要エリアである養成所内で入手できます。通常、それを解決する溝を入手直前に見ることになります。

**フックショットはインベントリを何スロット使いますか？**
プレイヤー報告では一貫して2スロットのアイテムとされており、キャラクターごとの6スロットのうち、携帯容量の大きな部分を占めます。

**『バイオハザード0』をクリアするのにフックショットは必要ですか？**
はい。キャンペーン中のいくつかの渡河はこれなしでは完了できないため、必須キーアイテムとして扱い、簡単に戻れない場所には決して置かないでください。
