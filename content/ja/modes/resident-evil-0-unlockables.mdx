バイオハザード0のアンロック要素は、クラシックシリーズの中でも特に風変わりなボーナス報酬であり、驚くほど多くのプレイヤーがその存在を知らないままキャンペーンをクリアしてしまっている。良い知らせは、そのほとんどが初めてエンドロールを迎えた瞬間に開放されることだ — 特別な難易度も、RTAも、完璧なランクも必要ない。落とし穴は、バイオハザード0のアンロック要素の中で最も優れた「無限弾薬」が、準備なしに挑む者を容赦なく罰するボーナスモードの奥に隠されていることだ。本ガイドでは、獲得できるすべての要素、その入手方法、そして各報酬への最速ルートを解説する。

## バイオハザード0のアンロック要素：一目でわかる全リスト

バイオハザード0は2002年にゲームキューブで発売され、2016年にPC、PlayStation、Xbox、そして後にSwitch向けのHDリマスターとして復活した。両バージョンの追加要素は同一ではないが、同じ設計思想に従っている：ストーリーを一度クリアすれば、ボーナスメニューが目を覚ます。カプコンの[公式バイオハザードポータル](https://www.residentevil.com/)は、報酬を追い始める前に自分がどのバージョンをプレイしているかを確認するのに最適な場所だ。

| アンロック要素 | 条件 | 入手できるもの |
|---|---|---|
| リーチハンター | メインストーリーを1回クリア（難易度不問） | トレーニング施設を舞台にした独立したミニゲーム |
| リーチハンターのボーナスアイテム | 1回のプレイで規定数のリーチを確保 | メインキャンペーン用の追加武器と弾薬 |
| 無限弾薬 | 1回のプレイでリーチを100匹すべて回収 | 本編武器の弾薬が無限に |
| ウェスカーモード | メインストーリーを1回クリア（HDリマスターのみ） | アルバート・ウェスカーをレベッカのパートナーとしてキャンペーンをプレイ |
| ボーナスコスチューム | 特定のリリースや予約特典に同梱 | レベッカとビリーのコスチューム |
| 実績・トロフィー | 各種 | プラットフォーム上のコンプリート目標 |

初代バイオハザードから来た人にひとつ現実をお伝えしよう。RE0の本編の武器リストは固定だ。ゲームが渡してくれるものだけを手に入れ、それ以上はない。だからこそリーチハンターが重要なのだ。周回プレイで火力を確実に強化できる唯一の方法なのである。

## リーチハンターの解放方法

リーチハンターは目玉のボーナスモードであり、到達するのは驚くほど簡単だ。隠しトリガーも、本編内の収集要素も、制限時間内クリアの条件もない。

| 手順 | 行動 |
|---|---|
| 1 | メインストーリーを任意の難易度でクリア — イージーでもカウントされ、アンロック内容は変わらない |
| 2 | スタッフロール後にセーブして、正式なクリアデータを作る |
| 3 | そのクリアデータをロードし、モードメニューからリーチハンターを選択 |
| 4 | ビリーかレベッカを選択 — 選んだキャラでソロプレイ |
| 5 | トレーニング施設を巡回してリーチを回収し、報酬を受け取る準備ができたらプレイを終了 |

このモードでは固定装備でトレーニング施設に放り込まれ、100匹のリーチ — 緑50匹と青50匹 — を集めることになる。ゾンビ、ハンター、リーチモンスターが廊下を徘徊し、物資は意図的に乏しい。ひとりなのでパートナーザッピングの安全網はない。棚を調べている間、扉を守ってくれる相手はいないのだ。

コミュニティの報告は一貫して、リーチハンターを銃撃戦ではなくルート構築のパズルだと表現している。敵は倒す的ではなく回避すべき障害物であり、最速でクリアするプレイヤーはたいてい最も弾を撃たない者だ。

## リーチハンターの報酬ティア：スコアで実際に何が得られるか

報酬は、プレイを終了した時点で所持しているリーチの総数から計算される。ティアはゲーム内のどこにも説明されていないため、プレイヤーコミュニティが長年にわたって記録してきた。広く報告されている構成は次のとおりだ。

| 回収したリーチ | コミュニティ報告の報酬 |
|---|---|
| 30匹未満 | ボーナスなし — そのプレイは無駄になる |
| 30匹以上 | 第1ティア：メインキャンペーン用の火力ボーナス |
| 60匹以上 | 中位ティア：追加武器または弾薬のサポート |
| 90匹以上 | 上位ティア：より強力な本編ボーナス |
| 100匹すべて | 本編の無限弾薬 |

正確なアイテム名はオリジナル版とリマスター版で異なるが、段階の形は変わらない。しきい値を逃すと1つ下のティアに落ちるので、出口に向かう前に数匹余分に回収しておくといつも得だ。

ほとんどすべての人にとって重要なのは最後のティアだ。100匹すべてを確保することが、緊張感のあるキャンペーンを勝利のパレードに変える。ボーナスはセーブすると本編に引き継がれる。90匹台でまだプレイが続いているなら、そこで切り上げてはいけない — 引き返して飛ばした部屋を掃討しよう。

## ウェスカーモードとHDリマスターの追加要素

2016年のリマスターは、ボーナスラインナップに最大の変革をもたらした：ウェスカーモードだ。リーチハンターと同様、メインストーリーを1回クリアすると解放されるが、サイドモードを追加するのではなく、キャンペーン自体を変化させる。

| 要素 | 通常キャンペーン | ウェスカーモード |
|---|---|---|
| 操作キャラのペア | レベッカとビリー | レベッカとウェスカー |
| 解放条件 | 最初から利用可能 | メインストーリーを1回クリア |
| 特殊能力 | なし | 敵を一撃で倒せるダッシュアタック |
| 最適な用途 | 初回のストーリープレイ | 高速クリアと無双プレイ |

これはコスチュームの差し替えではない。ウェスカーの機動力は遭遇戦を根本から書き換える — 新規プレイヤーを足止めするハンターやリーチクリーチャーが、ただの段差程度になるのだ。ほとんどのプラットフォームではモードクリアに実績やトロフィーが紐づいており、ストーリーをすでに見た後の自然な回収ステップとなる。

リマスターはプラットフォームと地域に応じて両主人公のコスチュームも同梱しており、中でもレベッカのナース風コスチュームが最も有名だ。これらは見た目だけで、難易度や報酬には影響しない。注目すべきは、ウェスカーモードとコスチュームボーナスはリマスターの要素であり、ゲームキューブ版の経験者にはオリジナル版で見つけられないということだ。

## すべてをより早く解放するためのヒント

すべてを解放するのは順序と準備の問題だ。プレイヤーの経験から、次の優先順位が導き出される。

| 目標 | やること |
|---|---|
| リーチハンターを素早く解放 | ストーリーをイージーで進める — 難易度は解放に影響しない |
| 100匹ティアに到達 | 完全回収を目指す前にトレーニング施設の構造を覚える |
| リーチハンターを生き延びる | 敵と戦わず回避する。弾薬は有限だ |
| その後キャンペーンを楽にする | 報酬が適用されたらすぐにクリアデータをセーブする |
| 実績は最後に | ウェスカーモードは最後にプレイ — 彼のダッシュはほとんどの戦闘を無意味にする |

さらに、いくつかの習慣が役立つ：

- **アイテムの置き場所を計画する。** RE0にはアイテムボックスがないことで有名で、床に置いたものはそのままそこに残る。すべてを持ち歩くのではなく、何度も通る部屋に小さな保管場所を作ろう。
- **最初のリーチハンタープレイは偵察と考える。** 失敗しても失うのは時間だけであり、どの通路がどの部屋につながっているかを知ることはどんな武器よりも価値がある。
- **正しいセーブデータを保持する。** コミュニティの報告によれば、ボーナスはそれを獲得したクリアデータに適用されるため、リプレイする予定なら上書きしないように。
- **イージーでのプレイを飛ばさない。** モードの解放だけが目的なら、素早いイージープレイが最短でリーチハンターとウェスカーモードに到達させる。

無限弾薬が有効になれば、新たなプレイが残った実績の回収、初回に無視した武器の試用、そして所持品の心配なしに列車とトレーニング施設のパートを楽しむ最良の方法となる。

## FAQ

### リーチハンターを解放するにはバイオハザード0をハードでクリアする必要がありますか？

いいえ。リーチハンターはイージーを含む任意の難易度でメインストーリーをクリアすれば解放されます。難易度設定はバイオハザード0のアンロック要素のいずれも制限しないため、ボーナスコンテンツだけが目的なら初回プレイで自分を苦しめる必要はありません。

### 最初に狙うべきアンロック要素は？

リーチハンターを目指し、次に100匹ティアを狙いましょう。無限弾薬があれば、ウェスカーモードのクリアや残った実績を含め、他のすべてが楽になります。ボーナスコスチュームやギャラリー系の追加要素は見た目だけなので、後回しで構いません。

### オリジナルのゲームキューブ版にウェスカーモードはありますか？

いいえ。ウェスカーモードは2016年のHDリマスターで追加されたもので、2002年のゲームキューブ版には存在しません。オリジナル版をプレイしている場合、リーチハンターとその報酬ティアが実質的にボーナス要素のすべてです。

### リーチを100匹すべて集めるのにどれくらいかかりますか？

トレーニング施設をどれだけ熟知しているかによります。ほとんどのプレイヤーは、マップを覚えてしまえば完全回収は1回のプレイに無理なく収まると報告しており、最初の数回はルート、敵の配置、そしてどのリーチなら戦闘のリスクを負う価値があるかを学ぶことに費やされます。
