バイオハザード0はクラシックシリーズの異端児だ――前日譚であり、ゾンビだらけの列車に2人のプレイアブルキャラクターと共に取り残され、アイテムボックスはなく、パートナーのことを忘れれば確実に死ぬ。まさにそれがこのバイオハザード0ガイドの存在理由だ。本作は『バイオハザード1』『2』『3』で身につけた習慣を罰し、パートナーザッピングシステムは各部屋の計画の立て方を根本から変える。オリジナルのGameCube版でも、現行機やPCのHDリマスターでも、以下の基本を押さえれば、インベントリを整理し、弾薬のやりくりを現実的にし、2人の生存者を生かし続けられる。

## バイオハザード0 早見表

戦術に入る前に、自分が実際にどんなゲームを遊んでいるのかを知っておくと役立つ。バイオハザード0は固定カメラのサバイバルホラーで、1998年7月、初代バイオハザードの幕開けとなる洋館事件の数時間前に設定されている。

| 項目 | 知っておくべきこと |
|---|---|
| オリジナル発売 | 2002年、Nintendo GameCube |
| 現行版 | バイオハザード0 HDリマスター。現行機とPCで入手可能 |
| 時系列 | 1998年7月、初代バイオハザードの直前 |
| 主人公 | レベッカ・チェンバース（S.T.A.R.S. ブラヴォーチームの衛生兵）とビリー・コーエン（脱獄囚、元海兵隊員） |
| 主な舞台 | エクリプト急行、アンブレラの管理訓練施設、地下研究所、処理施設 |
| 特徴的なシステム | パートナーザッピングシステム — キャラクターをいつでも切り替え |

リメイクしか遊んだことがないなら、タンクコントロール、意図的にゆっくりしたテンポ、資源不足のプレッシャーを覚悟しよう。オリジナルを遊んだことがあるなら、それらすべてに加えてもう一つの悩みの種がある。装備させ、位置取りを考え、時には救助しなければならない2人目のキャラクターだ。

## パートナーザッピングシステムを極める

パートナーザッピングシステムはバイオハザード0を定義するメカニクスだ。スクリプトシーン以外ならほぼいつでも、レベッカとビリーの操作を切り替えられる。操作していないキャラクターは同行し、ダメージを受け、何も消費せず、おおむね動く障害物――あるいは予備のポケット――として振る舞う。

切り替えは単なる目新しさではない。効率的に攻略するための手段であり、2人のキャラクターには本当に異なる長所がある。

### レベッカ vs. ビリー：役割分担

| 特性 | レベッカ・チェンバース | ビリー・コーエン |
|---|---|---|
| 最大体力 | 低い | 高い |
| ハーブ調合 | 可能 — ハーブの組み合わせを担当 | 不可 — 完成した回復アイテムを渡す |
| 初期装備 | ハンドガン、ナイフ | ナイフ |
| 戦闘での最適役割 | 遠距離支援、弾薬管理 | 前線、攻撃を受け止める |
| 探索での最適役割 | 化学パズル、回復アイテムの備蓄 | 重火器の運搬 |
| 物語上の役割 | ブラヴォーチームの衛生兵、研究作業 | 戦闘経験を持つ元海兵隊員 |

**実践ルール:** レベッカは調合。ビリーは運搬。多くの成功したプレイでは、レベッカがばらばらのハーブを強力な回復アイテムに変え、ビリーがショットガン、重い弾薬、その他インベントリを圧迫するものを運ぶ。

### 切り替えるべき時（と、そうでない時）

- **ドアの前で切り替え、入った後ではない。** 部屋にスクリプトイベントがあるなら、先に適切なキャラクターをそこに立たせておきたい。
- **パートナーを物陰に残す。** ゾンビの進路上に立つ同行者は、こちらへのただのダメージ源だ。
- **戦闘中に切り替えない**。もう一方の武器が必要な場合を除いて。切り替えアニメーションとAIのリセットで貴重な数秒を失う。
- **ボス部屋の前に両者のインベントリを確認する。** プレイヤー経験が一貫して示すのは、本作で死ぬ最大の原因は、弾薬を間違った人物のポケットに入れたままボスに挑むことだ。

## アイテムボックスなしのインベントリ管理

ベテランを最もつまずかせる変更点はこれだ。バイオハザード0にはアイテムボックスがない。落としたアイテムは床に落ち、戻れなくなるスクリプトシーケンスで移動させられない限り、その部屋にゲーム終盤まで残る。各キャラクターのスロットは6つで、いくつかの重要アイテムはそのうち2つを占める。

つまりインベントリ計画は*そのまま*ルート計画になる。コミュニティの報告では、中盤は「引っ越しの日」のように、再訪すると分かっている部屋の間で装備を運び続けるとよく表現される。

| アイテム種別 | 常に持つ？ | 理由 |
|---|---|---|
| ハンドガンとその弾薬 | はい、常に | 基本ダメージ源で最も一般的な弾薬 |
| ショットガンまたは重火器 | はい、ビリーに | 緊急時の群れ制御 |
| 調合済み回復アイテム | はい、少なくとも2つ | まずい部屋ひとつで体力バーが全部消える |
| フックショット | 必要な時だけ | 2スロット占有。隙間を渡った瞬間に捨てる |
| 使わない弾薬タイプ | いいえ | 再び通るハブ部屋に保管 |
| 予備の鍵アイテム | いいえ | ドアを開けたら鍵はただの重り |

### 攻略を救う5つのインベントリ習慣

1. **エリアごとにハブ部屋を決める。** 訓練施設の大広間や列車の中央車両は絶好の保管場所になる。
2. **フックショットは使った直後に捨てる。** 本作で最も不満の声が多いアイテムの一つであるのには理由がある。
3. **同じ武器を重複して持たない。** ハンドガン2丁は速く殺せず、4スロットを食うだけ。
4. **カットシーンの多い部屋の前でアイテムを落とす。** シーケンスによっては移動させられ、置き去りにしたものは失われる。
5. **大きなアイテム整理の前にセーブする。** インクリボンは有限だが、20分のルートをやり直す忍耐も有限だ。

## 武器、弾薬、戦闘経済

バイオハザード0ではそれなりの武器庫が与えられるが、弾薬経済は厳しい。良い弾はほとんど足りないので、安い弾は安い敵に使い、重火器はそれに値する相手のために取っておくのが目標だ。

| 武器 | 主な持ち主 | 最適な用途 |
|---|---|---|
| ナイフ | 両者 | 無料ダメージ。倒れた敵や這う敵のとどめ |
| ハンドガン | レベッカ（序盤）、以降はどちらでも | 標準的なゾンビ。弾薬は豊富 |
| ショットガン | ビリー | 近距離の一撃、リーチの群れ、狭い通路 |
| グレネードランチャー | どちらでも | 敵の群れと中堅モンスター |
| マグナム | どちらでも | ボスのみ。弾薬は希少 |
| サブマシンガン | どちらでも | パニック時。ただし弾薬消費が速い |
| ロケットランチャー | 最終エリア | ボスのとどめ。1発1発を貴重品として扱う |

**難易度を問わず有効な戦闘のコツ:**

- 目指すのは撃破ではなくよろけ。よろけたゾンビは横を通り過ぎられるゾンビだ。
- 通常敵にマグナムやグレネード弾を浪費しない。最終ボスの2部屋前で後悔する。
- 一部のリーチ系の敵は起き上がる癖がある。プレイヤーの報告では、完全に倒すには銃弾より火を使ったとどめの方が信頼できる。
- ドアを通って後退する。敵AIがリセットされ、無料で態勢を立て直せる。

## ボス戦：何が来るか、どう準備するか

このセクションはネタバレを控えめにするが、各主要戦闘の形は知っておくべきだ。空のショットガンで覚える羽目にならないために。

| ボス | 場所 | 準備と戦略 |
|---|---|---|
| リーチ人間型 | 列車セクションの終わり | 距離を取り、常に回り込み、ハンドガンとショットガンの弾に頼る |
| 感染したコウモリ | 訓練施設 | 急降下をかわし、着地の隙に重い弾を叩き込む |
| 巨大グモ | 訓練施設 | 動き続けて糸を避け、近距離でショットガン |
| プロトタイラント | 地下研究所 | マグナムとグレネード弾を温存。突進後の隙を攻める |
| 最終ボス | 終盤エリア | 2段階戦 — 最大限の回復と残っている最良の弾を持ち込む |

手強い通常敵にも触れておく。エリミネーター（素早く攻撃的な霊長類）とプレイグクロウラーは立ち止まることを罰し、ハンターは準備不足のキャラクターを一回の飛びかかりで首をはねることがある。これらを見たら、戦うか逃げるかを即断する。優柔不断が死を招く。

## パズル、セーブ、スピードのコツ

バイオハザード0のパズルは、頭の体操というより主にアイテムの運搬経路に関するものだ。研究所の薬品調合シーケンスが最も手間がかかる。レベッカが色の付いた薬品を組み合わせ、進行に必要な化合物を作る。順番を間違えると保管室まで戻る無駄な往復が発生する。

| 状況 | 賢い行動 |
|---|---|
| ボスのドアの前 | セーブし、操作するキャラクターに重い弾をすべて移す |
| インクリボンが少ない | ボス前と、後戻りできないルート決定の前だけセーブ |
| 長いバックトラックが待っている | まず落としたアイテムを1つのハブ部屋に集約 |
| 化学が必要なパズル | レベッカを送る。ビリーにはクリアできない |
| 最後の回復アイテム1つ | 単品で使わず、レベッカにハーブを調合させる |

より速いクリアタイムを狙うなら、最大の短縮は戦闘スキルではなくルート計画から生まれる。アイテムをどこに落とすか図を描き、不要な移動を避け、見えるものすべてを殺したい衝動を抑えよう。

## アンロック要素とやり込み

バイオハザード0をクリアしても終わりではない。本作はクリア報酬として追加コンテンツを用意し、2周目の感触を変える。

| アンロック | 入手方法 | 重要な理由 |
|---|---|---|
| リーチハンター ミニゲーム | メインストーリーをクリア | 訓練施設でリーチチャームを集める独立したチャレンジモード |
| ボーナス武器とコスチューム | 本編クリアとリーチハンターの目標達成 | 高難度攻略がはるかに楽になる |
| ウェスカーモード（HDリマスター） | キャンペーンをクリア | レベッカと共にアルバート・ウェスカーを操作。まったく異なるツールキット |

リーチハンターは多くのプレイヤーにとっての目玉だ。物語を取り払い、訓練施設をコンパクトで緊張感のある宝探しに変える。本編のアイテム管理が楽しいなら、このモードはその最も純粋な形だ。

## FAQ

**バイオハザード0の前にバイオハザード1をプレイする必要はありますか？**
いいえ、ただし役には立ちます。バイオハザード0は前日譚なので物語は単独で成立する。しかし固定カメラの操作、インクリボンによるセーブ、パズルの論理はすべて初代から受け継がれている。このバイオハザード0ガイドを入門点として使うなら、現代のリメイクより学習曲線は急だと覚悟しよう。

**なぜバイオハザード0にはアイテムボックスがないのですか？**
2人キャラクターの仕組みをさらに推し進めるための意図的なデザインだ。装備をマップ上でテレポートさせる代わりに物理的に運ばせることで、パートナーザッピングシステムが戦闘だけでなく物流面でも重要になる。

**武器は誰に持たせるべきですか — レベッカかビリーか？**
ビリー。彼は体力が多いので、前線で戦う際のミスを生き延びられる。レベッカにはハンドガン、回復アイテムの備蓄、化学関連の重要アイテムを渡そう。

**リーチハンターはアンロックする価値がありますか？**
多くのプレイヤーにとっては、はい。短く集中しており、このバイオハザード0ガイドが強調する技能――ルート計画、弾薬の節約、戦う代わりに逃げるべき時を知ること――をそのまま報いてくれる。
